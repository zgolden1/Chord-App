About this chart

ChordFlow estimates chords from the recording, so treat the chart as a strong draft and check it by ear. It works best on songs with a steady beat and repeating sections. It can miss short chords, passing chords and the intro. A “?” means the app is unsure and the grey note under it shows the other likely chord. “Triads only” hides 7ths and slash chords. Extensions pick up sustained notes, which in a vocal song can include the melody. Tempo is an estimate. Slow-down uses your browser’s pitch-preserving playback. Spotify and Apple Music streams can’t be analyzed, so use files you own.

Offline analysis (optional)

For voicings read from the actual notes, run analyze.py on your computer. It separates the stems with Demucs, transcribes notes with Basic Pitch, and writes a small .chordflow-notes.json file. On the Keys tab, tap “Add analysis file” and pick it, using the same audio file you loaded here. Nothing is uploaded.
